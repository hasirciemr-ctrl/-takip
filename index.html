🌐 GitHub Pages İle Web Sitesi Yapma Rehberi

  1. GitHub Hesabı Açın: github.com adresine gidin ve ücretsiz hesap oluşturun.
  2. Yeni Depo (Repository) Oluşturun: Sağ üstteki "+" ikonuna tıklayıp "New repository" seçeneğini seçin. Depo adını örn: sevkiyat-takip yapın ve Public işaretleyin.
  3. Dosyayı Yükleyin: Bu HTML kodunu bilgisayarınıza index.html adıyla kaydedin. GitHub deposu içinde "uploading an existing file" linkine basarak index.html dosyasını yükleyin ve "Commit changes" butonuna basın.
  4. Yayınlayın (Pages): Deponuzun Settings > Pages sekmesine gidin. Branch kısmını main veya master seçip Save butonuna basın.
  5. Ortak Adresiniz Hazır! 1-2 dakika içinde size verilen https://kullaniciadi.github.io/sevkiyat-takip/ adresiyle tüm çalışanlarınız projeye erişebilir!
